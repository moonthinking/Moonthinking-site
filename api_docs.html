API para bots

Para que un bot o automatización pueda crear, editar o borrar vacantes y artículos del blog directamente.

Todas las peticiones deben incluir el encabezado X-API-Key: {{ api_key }}.
Este valor viene de la variable de entorno BOT_API_KEY del servidor — cámbialo antes de usarlo en producción.

Vacantes

GET /api/bot/vacancies — lista todas las vacantes.

GET /api/bot/vacancies/<id> — detalle de una vacante.

POST /api/bot/vacancies — crea una vacante. Body JSON, campo obligatorio: title. Opcionales: location, modality, salary_display, salary_tier (blue/gold), positions, is_confidential, company_label, objetivo, responsabilidades, requisitos, prestaciones, status (active/draft/closed), published_at (YYYY-MM-DD).

PUT /api/bot/vacancies/<id> — actualiza cualquiera de los campos anteriores.

DELETE /api/bot/vacancies/<id> — elimina la vacante.

Blog

GET /api/bot/posts — lista todos los artículos.

GET /api/bot/posts/<id> — detalle de un artículo.

POST /api/bot/posts — crea un artículo. Body JSON, campos obligatorios: title, body. Opcionales: category, reading_time, status (published/draft), published_at.

PUT /api/bot/posts/<id> — actualiza cualquiera de los campos anteriores.

DELETE /api/bot/posts/<id> — elimina el artículo.

Ejemplo

curl -X POST https://tu-dominio.com/api/bot/vacancies \
  -H "X-API-Key: {{ api_key }}" -H "Content-Type: application/json" \
  -d '{"title":"Analista de Nómina","salary_display":"$28,000 MXN"}'
